# 📱 منيو مطعم Temo (Hot Which) الرقمي لطاولات الصالة عبر كود الـ QR

نسخة مستقلة بالكامل مخصصة للطاولات داخل صالة المطعم كبديل عصري وسريع عن المنيو الورقي. يمكن للزبائن مسح كود الـ QR بكاميرا هواتفهم لتصفح الأصناف والأسعار وحساب الفاتورة وطلب الويتر أو إرسال الطلب مباشرة عبر واتساب.

---

## 🌟 ميزات المنيو الرقمي المستقل

1. **مستقل بالكامل (100% Standalone)**:
   - يحتوي المجلد على جميع ملفاته (`index.html`, `style.css`, `script.js`, `assets/`, `qr-code.png`, `print-stand.html`).
   - يمكن رفعه كمسار في مستودعك الحالي أو كـ Repository منفصل تماماً على جيت هاب.
2. **تصميم فخم وخفيف مخصص للهواتف (Mobile-First Glassmorphism)**:
   - واجهة داكنة راقية بهوية مطعم تيمو وتأثيرات اللهب والإضاءات الزجاجية.
   - سرعة تحميل فائقة واستهلاك بيانات منخفض جداً لزبائن الصالة.
3. **أقسام المنيو والأسعار (87 صنفاً عبر 14 قسماً)**:
   - شريط تصنيفات أفقي مثبت للتنقل السريع بين الأقسام.
   - محرك بحث فوري لتصفية الأصناف بالمكونات أو الأسماء.
   - دعم كامل للأسعار المزدوجة (سوري / فرنساوي) لقسم الغربي.
4. **حاسبة الفاتورة وسلة الطاولة التفاعلية**:
   - إمكانية إضافة وجبات للطلب وتعديل الكميات لحظياً.
   - حساب إجمالي الفاتورة للزبون قبل استدعاء الويتر.
   - إرسال تفاصيل الطلب مع رقم الطاولة والملاحظات بضغطة واحدة إلى واتساب المطعم.
5. **خدمة الطاولة واستدعاء الويتر**:
   - أزرار مباشرة لطلب الويتر أو طلب الفاتورة والحساب لطاولة محددة.
6. **ستاند طاولة مجهز للطباعة المباشرة (`print-stand.html`)**:
   - تصميم ستاند أكريليك / كارت طاولة أنيق مقاس A5 / A6.
   - مولد QR تفاعلي يتيح تغيير رابط الموقع أو رقم الطاولة وتحديث الـ QR فوراً.
   - جاهز للطباعة مباشرة بضغطة زر (Ctrl + P).

### 🚀 خطوات الرفع السريع إلى مستودع `temo-menu`:

افتحي موجه الأوامر (Terminal أو PowerShell) في مجلد `qr-menu` ونفذي الأوامر التالية:

```bash
cd "d:\Desktop\frontend track\Hot Which temo\qr-menu"
git init
git add .
git commit -m "feat: initial release of Temo Dine-In QR Menu"
git branch -M main
git remote add origin https://github.com/mennakotb9905/temo-menu.git
git push -u origin main --force
```

بعد الرفع، ادخلي على إعدادات المستودع في GitHub:
1. اذهبي إلى **Settings** -> **Pages**.
2. تحت **Branch** اختاري `main` ثم اضغطي **Save**.
3. سيعمل الرابط `https://mennakotb9905.github.io/temo-menu/` فوراً!

## 🖨️ طباعة كود الـ QR وستاندات الطاولات

1. افتحي ملف `print-stand.html` في المتصفح.
2. يمكنك تعديل الرابط إن لزم، أو كتابة رقم الطاولة (مثلاً: 1، 2، 3...).
3. اضغطي على زر **"طباعة الستاند الآن"** أو اضغطي `Ctrl + P` لطباعته بجودة عالية لوضعه على طاولات الصالة.
4. صورة كود الـ QR الرسمية متوفرة أيضاً بجودة فائقة في الملفين:
   - `qr-code.png` (صورة عالية الدقة مدمج بها شعار المطعم).
   - `qr-code.svg` (صيغة متجهة Vector للطباعة الكبيرة غير المحدودة).
